# AK Furs — тестовое задание AI-ассистента

Пересчёт Q1–Q4 из выгрузок CRM, банка, справочника цен и клиентских переписок. Q5 — отдельная записка руководителю и продолжение диалога C0010.

**Статус: структура и документация.** CLI, JSON Schema, зависимости, тесты и итоговые ответы ещё не созданы. Работоспособность решения не проверялась.

## Входы и будущий запуск

Исходный комплект хранится локально в `inbox/`: четыре выгрузки, шаблон ответа и ТЗ. Для будущего запуска предусмотрен отдельный `data/` с четырьмя файлами без переименования и ручного редактирования:

```text
data/
├── 01_crm_orders_export.csv
├── 02_bank_statement_rub.csv
├── 03_catalog_prices_reference.xlsx
└── 04_client_chats.zip
```

`inbox/` сохраняется без изменений; `data/` сейчас пуст. Оба каталога исключены из Git. Шаблон и ТЗ определяют правила, но не являются операционными входами CLI. XLSX нужно сохранять целиком со скрытыми листами.

Целевой интерфейс, **пока не реализованный**:

```bash
python solve.py data/ > answers.json
```

Будущий запуск должен пересчитывать весь JSON из сырья. В stdout допускается только JSON, диагностика направляется в stderr; блокирующая ошибка означает ненулевой код завершения. Версия Python, зависимости и способ AI-анализа Q4 ещё не выбраны. Команды установки появятся после их выбора и проверки.

## Проверки и ограничения

Проверки оформления фиксируются в журнале ревью. Тесты расчётов, холодный запуск, анализ новых чатов и сверка с эталоном не выполнялись. Закрытый эталон работодателя недоступен.

Исходные данные, `answers.json`, Q5 и AI-экспорты не входят в Git. Подтверждение работы с AI и описание реальной ошибки агента готовятся отдельно после проверки содержимого. Решение предназначено для конкретного задания; промышленная автоматизация ателье не входит в его область.
