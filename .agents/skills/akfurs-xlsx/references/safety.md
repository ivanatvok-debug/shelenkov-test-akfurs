# Область адаптера

Поддержаны .csv и .xlsx. Inspect перечисляет все листы, включая hidden/veryHidden,
исходные типы/number_format, формулы, cache и точные XML numeric lexemes.
Числовой формат `0000` не превращает numeric 1 в подтверждённый ID `0001`:
исходный тип/формат нужно учесть в отдельном контракте нормализации.

Новый XLSX содержит literal strings; редактирование с сохранением произвольных
charts/макросов/формул/стилей исходной книги в этот adapter не входит.
CSV не несёт Excel number_format: при открытии в Excel импортируй ID как текст.
Апостроф в безопасном CSV — явное защитное преобразование, включая отрицательные
строки сумм; для финансовых расчётов используй raw XLSX или canonical JSON,
не этот профиль CSV без обработки отмеченных преобразований.

По умолчанию бюджет: 16 MiB распакованного OOXML, 10 000 ZIP members,
100 000 ячеек. Entities/DOCTYPE и повторные ZIP members отклоняются.
Автоматического пересчёта и запуска LibreOffice нет. Команда
`require-recalculation` возвращает отказ, пока пересчёт не выполнен отдельной
проверенной процедурой на копии; наличие программы не доказывает расчёт.

Это локальная защита выбранных операций, не sandbox для всех вредоносных книг.
