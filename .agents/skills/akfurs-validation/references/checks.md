# Проверяемые инварианты v1.0

1. JSON без повторных ключей и nonfinite значений; полный JSON Schema Draft 2020-12.
2. Обязательные поля, типы, version и коллекции локального протокола.
3. Каждая исходная строка заказа ровно один раз по source_index.
4. raw order/transaction trace совпадает с исходными записями и координатами.
5. Десятичные строки, валюта, ISO-дата и нормализованные значения согласованы.
6. Подтверждённая уникальная идентичность по разрешённому exact/composite ключу;
   невалидный связанный источник не снимает неоднозначность.
7. Настраиваемые date/amount tolerances и разрешения partial/group/refund.
8. Суммы links и aggregate totals независимо пересчитаны точной рациональной арифметикой.
9. Нет повторного учёта транзакции без полного явного allocation.
10. Нераспределённые остатки и невалидные транзакции сохранены по source_index.
11. Каждому дефектному источнику соответствует ровно одно исключение с причиной.
12. MATCHED не выводится из fuzzy/normalized suggestions; причины и uncertainty
    соответствуют статусу. Покрытие JOIN сверяется через исходные ключи/связи,
    а не через суммарное количество строк после потенциальной потери.

Схема не доказывает смысловую правильность. Это проверка canonical protocol,
не трактовок реальных назначений/чатов или закрытого эталона работодателя.
