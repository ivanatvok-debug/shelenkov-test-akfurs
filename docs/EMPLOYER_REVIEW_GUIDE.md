# Руководство проверяющему

Проект рассчитывает Q1–Q4 одним Python CLI. Готовые ответы, Q5 и материалы работы с AI передаются отдельно. Исходные данные задания не публикуются.

## Проверка вручную

1. Прочитайте [README](https://github.com/ivanatvok-debug/shelenkov-test-akfurs/blob/main/README.md). Подготовьте окружение и четыре входных файла.
2. Запустите тесты по команде из README. Они используют синтетические данные и не обращаются к моделям.
3. Для полного расчёта настройте вход в Codex CLI. Проверьте разрешение на передачу переписок в OpenAI, доступные лимиты и возможные расходы.
4. Выполните команду расчёта из README.
5. Проверьте формат `answers.json` по исходному `answers_template.json`. Сверьте ответы с исходными данными.
6. Прочитайте Q5: аналитическую записку и ответ клиентке.
7. Просмотрите отчёт проверок и приложенные материалы работы с AI.

## Проверка AI-агентом

1. Прочитайте [AGENTS.md](https://github.com/ivanatvok-debug/shelenkov-test-akfurs/blob/main/AGENTS.md) и инструкции соответствующих каталогов.
2. Используйте исходное ТЗ и `answers_template.json` из переданного комплекта.
3. По [матрице требований](https://github.com/ivanatvok-debug/shelenkov-test-akfurs/blob/main/docs/REQUIREMENTS_MATRIX.md) найдите реализацию, тесты и основания каждого ответа. Основной код расположен в `solve.py` и `src/akfurs/`.
4. Сверьте расчёты с исходными записями. Для Q4 проверьте как отмеченные, так и неотмеченные чаты. Учитывайте автора сообщения, смысл и порядок цены и приглашения.
5. Не ограничивайте проверку Q4 совпадением количества чатов или наличием цитат. Сохранённые AI-основания не являются человеческой разметкой.
6. Сопоставьте версии кода, входов и ресурсов с приложенными хешами. Перед изменениями или новыми запусками проверьте разрешённую область работы.

## Состав комплекта

### Код

- Исполняемый код, контракт ответа и тесты.
- Документация и сведения о сторонних компонентах.
- История Git в формате bundle. При наличии незакоммиченных изменений — отдельный patch.

В кодовый архив не входят исходные данные, `private/`, `.venv`, `.git/config` и учётные данные.

### Отдельные материалы

- `answers.json` полного успешного запуска.
- Q5: аналитическая записка и ответ клиентке.
- Отчёт проверок и карта происхождения результатов.
- Перечень файлов с SHA-256.
- Очищенный экспорт работы с AI с указанием охваченной истории.
- Пример обнаруженной и исправленной ошибки AI.

## Проверенная среда и ограничения

- Проверенная среда: Linux, Python 3.12.3 и установленное окружение зависимостей.
- Полный холодный запуск на 150 чатах: **17 мин 15,4 с**.
- Windows и установка в новом окружении не проверены.
- Адаптер Claude проверен локальными тестами. Живой запуск через Claude не выполнялся.
- При ошибке программа не выдаёт полный JSON. Пустой файл или неполная обработка чатов не считаются успешным результатом.

Подробности: [архитектура решения](https://github.com/ivanatvok-debug/shelenkov-test-akfurs/blob/main/docs/ARCHITECTURE.md).
